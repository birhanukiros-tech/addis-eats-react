# Fetch and Display Live Data

This is a simple JavaScript app that gets dish data from a public API and displays it on the page.

## Features

- Shows a loading message
- Fetches dishes from the API
- Displays the dishes
- Shows an error message if the request fails
- Has a refresh button

## What I practiced

I practiced `fetch()`, `async/await`, `try/catch`, JSON, and working with API data.
