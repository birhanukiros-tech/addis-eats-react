# TeleBirr Tip & Split Calculator

A JavaScript calculator that calculates:
- Tiered tip based on the bill amount
- Service fee
- Total bill
- Amount per person

## Requirements

- [x] Convert bill using Number()
- [x] Use 10% tip when bill is over 300 ETB
- [x] Use 5% tip when bill is 300 ETB or less
- [x] Calculate total
- [x] Calculate amount per person
- [x] Use a template literal
- [x] Use switch for TeleBirr / CBE Birr service fee
- [x] Run with Node.js
