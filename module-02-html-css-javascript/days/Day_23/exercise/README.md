# 🍽️ Addis Eats

A food discovery app for Addis Ababa with search, filters, and a persistent cart.

## Features

- 🏙️ Browse restaurants in a responsive grid
- 🔍 Live search on input (name, cuisine, dishes)
- 🎯 Filter by cuisine, price, and rating
- 🛒 Cart with add/update/remove (event delegation)
- 💰 ETB total with reduce()
- 💾 Cart persists in localStorage
- 🌙 Dark/Light theme toggle
- 📱 Fully responsive
