# 🍽️ Addis Eats

Addis Eats is a responsive food ordering web application designed for customers in Addis Ababa, Ethiopia.

The project has two main parts:

1. Customer-facing food ordering website
2. Admin dashboard for managing dishes and customer orders

The application was built using HTML, CSS, and JavaScript. Data is stored in the browser using Local Storage and Session Storage, so no backend server is required.

---

## 🚀 Features

### Customer Features

The customer website includes:

- Browse food menu
- Live food search
- Category filtering
- Ethiopian food category
- Pizza category
- Burgers category
- Drinks category
- Add items to cart
- Increase and decrease item quantity
- Remove items from cart
- Live cart total
- Cart persistence using localStorage
- Checkout form
- Customer name validation
- Phone number validation
- Delivery area validation
- Order confirmation
- Loading state
- Empty menu state
- Empty cart state
- Error handling
- Responsive design
- Order history
- Favorite dishes
- Dish details
- Reorder functionality
- Special instructions
- Cart badge
- Formatted ETB currency
