# Addis Eats — Day 26 React Exercise

## What it is

This is a simple React practice project built with Vite.

The project demonstrates:

* JSX
* React components
* Props
* Destructuring
* Component composition
* Arrays
* `map()`
* React keys

It displays a static Addis Eats food menu using reusable `Dish` components.

## How to run

1. Clone or download the project.
2. Open the project folder in the terminal.
3. Install the dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL shown in the terminal.

## Components

* `App` — main component that composes the page.
* `Header` — displays the Addis Eats heading and menu title.
* `Dish` — reusable component that receives `name` and `price` through props.
